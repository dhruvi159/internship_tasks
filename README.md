# Summer Internship - Core Python Tasks

A collection of fundamental Python programming exercises covering string operations, control flow, functions, data structures, and object-oriented programming.

## 📋 Project Structure

```
internship_tasks/
├── lab-2/          # String Operations
├── lab-3/          # Control Flow & Loops
├── lab-4/          # User-Defined Functions
├── lab-5/          # Dictionaries & Data Management
├── lab-7/          # Object-Oriented Programming
├── studentInfo.txt # Student information data
└── studentMarks.txt # Student marks data
```

## 🔍 Labs Overview

### Lab-2: String Operations
**File:** [lab-2/lab-2.py](lab-2/lab-2.py)

Covers fundamental string manipulation techniques:
- Reverse a string using slicing
- Word-wise reversal
- Character interchange/swapping
- String joining with delimiters
- String replacement operations

### Lab-3: Control Flow & Loops
**File:** [lab-3/lab-3.py](lab-3/lab-3.py)

Practices conditional statements and input validation:
- Character validation (alphabet check)
- Positive/negative number classification
- Odd/even number operations
- Conditional logic chains
- Grade calculation based on marks

### Lab-4: User-Defined Functions
**File:** [lab-4/lab-4.py](lab-4/lab-4.py) & [lab-4/file_task.py](lab-4/file_task.py)

Introduces functions and lambda expressions:
- Function definition and parameters
- Variable argument functions (*args)
- List operations (concatenation, sum, min/max)
- Lambda functions for data transformation
- Functional programming concepts

### Lab-5: Data Structures & Dictionaries
**File:** [lab-5/task-1.py](lab-5/task-1.py), [lab-5/task-2.py](lab-5/task-2.py), [lab-5/task-3.py](lab-5/task-3.py)

Works with dictionaries and data management:
- Dictionary creation and manipulation
- Student record storage (roll number, name, marks)
- Input validation and data collection
- Data organization and retrieval

### Lab-7: Object-Oriented Programming
**Files:** [lab-7/task-1.py](lab-7/task-1.py) through [lab-7/task-6.py](lab-7/task-6.py)

Implements OOP concepts:
- Class definition and initialization
- Student information management (StudentInfo class)
- Grade calculation and averaging (StudentMarks class)
- Multiple attributes and methods
- Data encapsulation and organization
